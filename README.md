\# College Chatbot



A college enquiry and admission support chatbot built with Python and Flask.

It answers questions about courses, fees, hostels, transport, placements and

admissions in English and Tamil, with voice input and read-aloud in the browser.



> Note: This project uses sample data for demonstration. It is not official

> SRM information.



\## Features

\- Text chat with fuzzy keyword matching (difflib)

\- English and Tamil replies (googletrans)

\- Voice input and read-aloud using the browser's speech features

\- Course fees, hostel, transport, placement, timing and admission details



\## Run locally (Windows)



```

python -m venv venv

venv\\Scripts\\activate

pip install -r requirements.txt

python app.py

```



Then open http://127.0.0.1:5000 in your browser.
